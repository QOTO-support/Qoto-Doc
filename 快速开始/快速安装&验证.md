# 📦 快速安装&验证

本文档详细介绍智慧灌溉系统的安装和验证流程。

---

## 一、安装前准备

### 1.1 设备清单

**检查设备清单**：

| 设备   | 数量  | 说明          |
| ---- | --- | ----------- |
| 阀门产品 | 1台  | 强泰产品        |
| 磁控棒  | 1把  | 用于激活、手动操作磁控 |
| 手机   | 1台  | 安装IOTMGR应用  |

### 1.2 物料准备（可选）

**备用物料**：
- 本地区已开通联网数据SIM卡


### 1.3 安装环境

**安装注意事项**：
- 安装在信号好的位置；
- 防护等级IP67，室内外都可以安装，设备不能泡水，安装时请注意勿安装在易泡水区域；
- 使用太阳能供电时，请将设备安装在阳光充足的位置；
- 电池回收请按国家废电池回收流程处理，避免造成环境污染

## 二、设备激活上线
### 2.1 设备激活及开关验证

![资源文件/快速开始/ScreenShot_2026-05-19_110346_388.png|246](资源文件/快速开始/ScreenShot_2026-05-19_110346_388.png)
1. 休眠激活:磁控棒长置OFF键处5秒，设备发出嘀嘀嘀声，即设备激活。
2. 开关阀功能:磁控棒控制A键/B键，嘀一声单通阀门开启；磁控棒控制OFF键，嘀一声单通阀门关闭。

### 2.2设备添加

**账号注册及APP下载**
![资源文件/快速开始/ScreenShot_2026-05-19_133909_296.png](资源文件/快速开始/ScreenShot_2026-05-19_133909_296.png)
手机端：IOS系统手机、安卓系统手机在应用商城搜索“IOTMGR”下载APP，注册登录采用手机号或邮箱号。

**添加绑定设备**
- APP进入“设备”界面，点击右边“＋”号添加设备
- 扫设备的二维码或输入IEMI号→输入设备名称→添加
- 界面显示已添加的设备

**设备详情**
设备添加后，在列表对应设备的右边点击查看，进入设备详情。
设备详情主要包含内容：设备详情查看、设备参数查看及设置、设备操作、设备的历史记录、控制日志、上报日志、统计等。

### 2.2 等待上线

**上线时间**：
- 首次上线约1-2分钟
- 观察设备状态变化
- 检查设备在线状态

## 三、功能验证

### 3.1 数据采集验证

**验证步骤**：
1. 进入设备详情页
2. 查看阀门状态&传感器数据
3. 确认数据更新正常
4. 检查数据采集周期

**预期结果**：
- 阀门状态：显示当前阀门开度值（0%-100%）
- 土壤温湿度：显示当前温度/湿度值
- 数据更新：按采集周期更新

### 3.2 设备控制验证

**验证步骤**：
1. 进入设备控制页面
2. 选择阀门控制
3. 点击"打开"按钮
4. 观察阀门状态变化
5. 点击"关闭"按钮

**预期结果**：
- 阀门成功打开
- 阀门成功关闭
- 阀门开度状态反馈正确

### 3.3 告警配置验证

**验证步骤**：
1. 进入告警配置页面
2. 设置告警触发条件
3. 模拟触发条件
4. 检查告警通知

**预期结果**：
- 告警规则生效
- 告警通知及时

## 四、快速排障

### 4.1 SIM卡安装

**安装步骤**：
1. 打开设备SIM卡槽盖
2. 将SIM卡芯片朝下插入卡槽
3. 关闭卡槽盖并拧紧上盖螺丝

**注意事项**：
- SIM卡必须开通数据业务
- 支持当地运营商注网SIM卡
- 建议使用当地SIM卡或我司专用配套物联网SIM卡

### 4.2 天线安装

**安装步骤**：
1. 拧开设备天线保护套
2. 将天线接头安装在设备天线接口

**注意事项**：
- 确保天线连接牢固
- 外置天线避免被遮挡


### 4.3 太阳能光伏板连接

**接线方式**：
```
电源适配器输出
├── 正极(+) → 电源正极
└── 负极(-) → 电源负极
```

**电源参数**：

| 参数   | 规格         |
| ---- | ---------- |
| 输入电压 | DC 9-30V   |
| 推荐电压 | DC 12V/24V |
| 最大功率 | ≤10W       |

### 4.4 传感器连接

**RS485接线**：
```
RS485接口
├── A端子 → 传感器A端子
├── B端子 → 传感器B端子
└── GND端子 → 传感器GND端子
```

**传感器类型**：
- 土壤湿度传感器
- 流量传感器
- 温度传感器
- 水位传感器
