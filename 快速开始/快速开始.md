# 快速开始

本文档帮助您快速上手智慧灌溉系统。

---

## 一、准备工作

### 1.1 设备清单

| 设备     | 说明       |
| ------ | -------- |
| DTU控制器 | 核心控制单元   |
| 阀门     | 灌溉阀门     |
| 传感器    | 土壤湿度、流量等 |
| SIM卡   | 4G通信     |
| 电源适配器  | 12V供电    |

### 1.2 账号注册

**注册步骤**：
1. 访问强泰云平台
2. 点击"注册"
3. 填写注册信息
4. 验证邮箱
5. 登录平台

---

## 二、设备安装

### 2.1 DTU安装

**安装步骤**：
1. 安装SIM卡
2. 连接电源
3. 连接传感器和阀门
4. 固定设备

### 2.2 传感器连接

**接线方式**：
```
DTU RS485接口
├── A端子 → 传感器A端子
├── B端子 → 传感器B端子
└── GND端子 → 传感器GND端子
```

### 2.3 阀门连接

**接线方式**：
```
DTU继电器输出
├── COM端子 → 电源正极
├── NO端子 → 阀门正极
└── 阀门负极 → 电源负极
```

---

## 三、设备激活

### 3.1 添加设备

**步骤**：
1. 打开登录APP：IOTMGR
2. 进入设备管理页面
3. 点击"添加设备"
4. 扫描设备二维码或输入设备ID
5. 等待设备上线

### 3.2 设备命名

**建议命名规则**：
- 按位置：如"温室A区阀门"
- 按编号：如"阀门-001"

---

## 四、基础配置

### 4.1 网络配置

- 设备自动连接4G网络
- 自动连接强泰云平台

### 4.2 告警配置

**设置告警阈值**：
- 低电10%告警
- 设备离线告警
- 三天不充电告警

---

## 五、功能使用

### 5.1 手动控制

**操作步骤**：
1. 进入设备详情页
2. 找到控制按钮
3. 点击"打开"或"关闭"
4. 确认操作

### 5.2 定时任务

**创建任务**：
1. 进入定时任务页面
2. 点击"添加任务"
3. 设置任务名称和时间
4. 设置执行动作
5. 保存任务

### 5.3 数据查看

**查看数据**：
1. 进入设备详情页
2. 查看实时数据和历史曲线
