# 📶 4G通讯协议

本文档详细介绍强泰DTU控制器的4G通信协议。

---

## 一、协议概述

### 1.1 通信架构

4G通信模块负责DTU与云平台之间的数据传输，采用TCP/IP协议栈。

**通信架构**：
```
DTU设备 ←→ 4G网络 ←→ 云平台服务器
```

### 1.2 协议特点

**特点**：
- 支持LTE Cat.4标准
- 自动网络连接和重连
- 数据加密传输
- 低功耗设计

## 三、网络异常处理

### 3.1 异常类型

| 异常类型 | 原因 | 处理方式 |
|----------|------|----------|
| SIM卡错误 | SIM卡未插入或损坏 | 检查SIM卡 |
| 网络注册失败 | 信号弱或运营商问题 | 等待重试 |
| PDP激活失败 | APN配置错误 | 检查APN设置 |
| 连接超时 | 网络不稳定 | 自动重连 |

### 3.2 重连机制

**重连策略**：
- 首次重连：立即
- 二次重连：10秒后
- 三次重连：30秒后
- 后续重连：30分间隔
