# 📡 LoRaWAN协议

本文档详细介绍强泰DTU控制器的LoRaWAN通信协议。

---

## 一、协议概述

### 1.1 LoRaWAN简介

LoRaWAN是一种低功耗广域网络协议，适用于物联网设备的远距离通信。

**协议特点**：
- 远距离通信（可达数公里）
- 低功耗设计
- 支持大量设备接入
- 双向通信

### 1.2 应用场景

**典型应用**：
- 偏远地区设备通信
- 大面积农田监测
- 物联网传感器网络
- 低功耗设备连接

## 二、技术参数

### 2.1 LoRa模块参数

**型号**：Semtech SX1276

**技术参数**：

| 参数 | 规格 |
|------|------|
| 频率范围 | EU868/US915/CN470/AU915/AS923 |
| 输出功率 | 14dBm |
| 接收灵敏度 | -148dBm |
| 数据速率 | 0.3-50 kbps |
| 通信距离 | 可达10km（视距） |

### 2.2 频段选择

**频段配置**：
| 频段 | 适用区域 | 信道数 |
|------|----------|--------|
| EU868 | 欧洲 | 3个上行信道 |
| US915 | 北美 | 64个上行信道 |
| CN470 | 中国 | 32个上行信道 |
| AU915 | 澳洲 | 64个上行信道 |
| AS923 | 亚洲 | 9个上行信道 |

## 三、设备配置

### 3.1 设备身份标识

**设备标识**：
| 参数 | 说明 | 格式 |
|------|------|------|
| DevEUI | 设备唯一标识 | 16位十六进制 |
| AppEUI | 应用标识 | 16位十六进制 |
| AppKey | 应用密钥 | 32位十六进制 |
| NwkSKey | 网络会话密钥 | 32位十六进制 |
| AppSKey | 应用会话密钥 | 32位十六进制 |

### 3.2 配置步骤

**配置流程**：
1. 获取设备DevEUI
2. 在LoRaWAN网络服务器注册设备
3. 获取AppEUI和AppKey
4. 配置设备参数
5. 激活设备（OTAA方式）

### 3.3 网关配置

**网关要求**：
- 支持LoRaWAN协议
- 正确配置频段
- 连接网络服务器
- 配置信道计划

---

## 四、通信流程

### 4.1 OTAA激活流程

**激活步骤**：
1. 设备发送Join Request
2. 网关转发到网络服务器
3. 网络服务器验证设备
4. 网络服务器发送Join Accept
5. 设备获取会话密钥
6. 设备进入正常通信模式

**Join Request格式**：

| 字段     | 长度 | 说明         |
|----------|------|--------------|
| MHDR     | 1B   | 消息头       |
| DevEUI   | 8B   | 设备唯一标识 |
| AppEUI   | 8B   | 应用标识     |
| DevNonce | 2B   | 设备随机数   |
| MIC      | 4B   | 消息完整性码 |

### 4.2 数据传输

**上行传输**：
- 设备发送数据到网关
- 网关转发到网络服务器
- 网络服务器转发到应用服务器

**下行传输**：
- 应用服务器发送数据到网络服务器
- 网络服务器发送到网关
- 网关广播到设备

**数据速率**：
| SF | 数据速率 | 适用场景 |
|----|----------|----------|
| SF7 | 50 kbps | 近距离，高带宽 |
| SF12 | 2.9 kbps | 远距离，低带宽 |

### 4.3 消息类型

**消息类型**：
| 类型 | 说明 |
|------|------|
| Unconfirmed Data Up | 上行非确认消息 |
| Confirmed Data Up | 上行确认消息 |
| Unconfirmed Data Down | 下行非确认消息 |
| Confirmed Data Down | 下行确认消息 |
