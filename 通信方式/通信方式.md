# 通讯方式

本文档介绍智慧灌溉系统支持的通信协议和方式。

---

## 一、通讯方式概述

### 1.1 通讯架构

```
设备层                  网络层                  应用层
┌─────────┐            ┌─────────┐            ┌─────────┐
│ 传感器   │            │  4G网络  │            │ 云平台  │
│ 阀门     │──RS485───▶ │  LoRa   │──MQTT/HTTP▶│ API接口 │
│ DTU     │──蓝牙───▶   │      网络│            │ 数据库  │
└─────────┘            └─────────┘            └─────────┘
```

### 1.2 通讯方式对比

| 通讯方式 | 距离 | 功耗 | 速率 | 支持产品 |
|----------|------|------|------|----------|
| 4G | 远程 | 中 | 高 | 全部DTU产品 |
| LoRaWAN | 远程（长距离） | 低 | 低 | LoRa系列DTU |
| RS485 | 本地（短距离） | 低 | 中 | 部分产品 |
| 蓝牙 | 本地（极短距离） | 低 | 中 | 部分产品 |

## 四、选型建议

### 4.1 选择依据

| 因素 | 考虑要点 |
|------|----------|
| 距离 | 短距离用RS485/蓝牙，长距离用LoRaWAN或4G |
| 功耗 | 低功耗场景选择LoRaWAN |
| 数据量 | 大数据量选择4G |
| 可靠性 | 关键应用选择冗余方案 |

### 4.2 推荐方案

| 场景 | 推荐配置 |
|------|----------|
| 农田灌溉（大面积） | QT-DTU-LoRa + RS485传感器 |
| 园区灌溉（中等面积） | QT-DTU-4G + RS485传感器 |
| 家庭花园（小面积） | QT-DTU-4G（蓝牙配置） |
| 本地调试 | 蓝牙功能 |
