# 🔗 RS485协议

本文档详细介绍强泰DTU控制器的RS485通信协议（部分产品支持）。

---

## 一、协议概述

### 1.1 RS485简介

RS485是一种串行通信标准，适用于设备之间的短距离通信。

**协议特点**：
- 差分信号传输，抗干扰能力强
- 支持多点通信（最多200个节点）
- 传输距离可达1000米
- 半双工通信

### 1.2 应用场景

**典型应用**：
- DTU与传感器通信
- DTU与阀门控制器通信
- 多个DTU设备级联
- 本地设备数据采集

## 二、技术参数

### 2.1 接口参数

**电气特性**：
| 参数 | 规格 |
|------|------|
| 接口类型 | RS485半双工 |
| 传输速率 | 2400-9600 bps |
| 传输距离 | 可达1000米 |
| 节点数量 | 最多200个 |
| 工作电压 | DC 5V/24V |

### 2.2 接线方式

**标准接线**：
```
DTU RS485接口
├── A端子 → 设备A端子（差分正）
├── B端子 → 设备B端子（差分负）
└── GND端子 → 设备GND端子（可选）
```

**总线结构**：
```
主设备（DTU）←→ 从设备1 ←→ 从设备2 ←→ ... ←→ 从设备N
              ↖ 终端电阻（120Ω）↗
```

## 三、通信参数

# 1. **数据定义说明**

本通信基本信息

 波特率：9600(默认)

起始位：1

 数据位：8

停止位：1

校验：无校验。

地址：1(默认)

## 1.1 **数据的表示**

1） 本说明书中所有数据描述遵循以下标准MODBUS规则：

l 数据地址从0开始编号，并以字（16 bits）为单位进行传送，先传送高位值，再传送低位值。

l 如：对于地址0x000F，使用时先传送0x00，再传送0x0F。

l 数据值以字（16 bits）为单位进行传送，先传送高位值，再传送低位值。

l 如：对于值0x1234，先传送0x12，再传送0x34。

2） 本说明书中遵循以下规则

l HEX表示十六进制，DEC表示十进制。

l 数据地址由基地址和相对地址两部分组成，在数据定义处都给出了计算公式。

l 所有应用实例按标准MODBUS格式、十六进制进行描述。

附录1. **常见问题排查**

l **MODUS 异常应答**

当接收到的功能码为(发送功能码+0x80)时，说明通讯出现异常，需要根据接收到的异常码（Exception Codes）进行排查。

例：发送：03 01 04 A1 00 01 AD 18

    接收：03 81 02 C1 91

其中第2个字节为功能码为81（0x01+0x80），第3个字节为异常码02 ，表示发送的命令中有非法数据地址。

**异常码列表：**

|   |   |   |   |
|---|---|---|---|
|Code|   |名称|异常排查|
|DEC|HEX|
|1|0x01|非法功能码|1. 具体含义同MODBUS标准<br><br>2. 更多预定义的异常码请参考MODBUS标准。|
|2|0x02|非法数据地址|
|3|0x03|非法数据值|

B、 当有符号数大于或等于0x8000（10进制：32768），表示为负数，其转换方法如下：

以将有符号数0x8041（10进制：32833；大于32768，所以为负数）转为10进制为例：

第一步：将计算器设为“十六进制”状态，用0xFFFF减去0x8041，计算出来为0x7FBE。

第二步：将第一步计算出来的结果0x7FBE转换为10进制，即将计算器由“十六进制”状态切换到“十进制”，转换的结果为32702。

第三步：在上步的结果前加上负号，所以最后的结果为-32702。
