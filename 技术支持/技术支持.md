## 一、技术服务流程

### 1.1 问题反馈流程

**流程步骤**：
1. **问题描述**：详细描述故障现象
2. **信息收集**：提供设备信息或日志
3. **初步诊断**：技术支持初步判断
4. **解决方案**：提供解决方案或指导
5. **问题验证**：确认问题解决


**GitHub Issues 提交方式**

**访问地址**：[https://github.com/QOTO-support/Qoto-Doc/issues](https://github.com/QOTO-support/Qoto-Doc/issues)

**提交步骤**：

1. 点击「New issue」创建新的问题单
    
2. 选择对应问题模板（故障报告 / 技术咨询 / 功能建议）
    
3. 按模板要求填写设备信息、故障现象、复现步骤
    
4. 上传系统日志、错误截图等相关附件
    
5. 确认信息完整后点击「Submit new issue」提交
    

**服务说明**：提交后，您可随时在 Issues 中查看处理进度与回复。为了提高问题处理效率，请务必提供完整的设备信息与日志文件。
