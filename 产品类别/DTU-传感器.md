# 📊 DTU-传感器模块

本文档详细介绍DTU控制器支持的传感器模块。

---

## 一、传感器概述

### 1.1 支持的传感器类型

强泰DTU控制器支持多种类型的传感器接入：

| 传感器类型   | 测量参数  | 接口类型  |
| ------- | ----- | ----- |
| 土壤湿度传感器 | 土壤含水率 | RS485 |


### 1.2 传感器特点

**通用特点**：
- 高精度测量
- 低功耗设计
- 抗干扰能力强
