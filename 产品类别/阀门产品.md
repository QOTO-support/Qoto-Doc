## 一、产品概述

### 1.1 阀门系列

强泰自控提供多种型号的智能灌溉阀门，满足不同场景需求：

| 型号 | 规格 | 说明 |
|------|------|------|
| QT-F08 | 1/2" | 小型阀门，适合小面积灌溉 |
| QT-F12 | 3/4" | 中型阀门，适合中等面积灌溉 |
| QT-F30 | 1" | 大型阀门，适合大面积灌溉 |

### 1.2 产品特点

**通用特点**：
- 智能控制，支持远程操作
- 低功耗设计，节能环保
- 多种控制方式：手动、定时、智能
- 支持状态反馈和故障检测

## 三、安装指南

### 3.1 安装步骤

**安装前准备**：
1. 确认阀门型号与管道匹配
2. 准备安装工具（扳手、密封带等）
3. 关闭水源

**安装步骤**：
1. 清洁管道接口
2. 缠绕密封带
3. 安装阀门到管道
4. 连接电源线
5. 连接控制线到DTU
6. 开启水源测试

### 3.2 接线说明

**接线方式**：
```
DTU继电器输出
├── COM端子 → 电源正极
├── NO端子 → 阀门正极
└── 阀门负极 → 电源负极
```

**接线图**：
```
电源(12V)          DTU           阀门
  +───┬───+       ┌──────┐       ┌──────┐
      │           │  COM │───────│  +   │
      └───────────│  NO  │───────│      │
                  └──────┘       └──────┘
                    │               │
                    └───────────────┘
                         GND
```

## 四、控制方式

### 4.1 手动控制

**本地控制**：
- 通过按钮手动开关阀门
- 适合现场调试

**远程控制**：
- 通过云平台远程控制
- 支持手机APP和网页端

### 4.2 定时控制

**设置步骤**：
1. 登录云平台
2. 进入定时任务页面
3. 添加任务
4. 设置执行时间
5. 设置阀门动作
6. 保存任务

### 4.3 智能控制

**智能灌溉策略**：
- 根据土壤湿度自动控制
- 根据气象数据调整灌溉
- 联动其他设备

## 五、维护保养

### 5.1 日常维护

| 项目 | 周期 | 内容 |
|------|------|------|
| 清洁阀体 | 每月 | 清除表面灰尘和杂物 |
| 检查密封 | 每季度 | 检查是否漏水 |
| 润滑活动部件 | 每半年 | 涂抹润滑油 |
| 电气检查 | 每半年 | 检查接线端子 |

### 5.2 故障处理

**常见故障**：
| 故障 | 原因 | 解决方案 |
|------|------|----------|
| 阀门不动作 | 电源问题 | 检查电源和接线 |
| 阀门漏水 | 密封圈损坏 | 更换密封圈 |
| 阀门抖动 | 电压不稳 | 增加稳压电源 |
| 线圈发热 | 长时间通电 | 检查控制逻辑 |
