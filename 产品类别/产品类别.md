

本文档介绍强泰自控智慧灌溉系统的产品系列。

---

## 一、产品概述

### 1.1 产品架构

```
智慧灌溉系统
├── DTU控制器系列
│   ├── QT-DTU-4G
│   └── QT-DTU-LoRa
│
├── 阀门系列
│   ├── QT-F08 (1/2")
│   ├── QT-F12 (3/4")
│   └── QT-F30 (1")
└── 传感器系列
│    ├── 土壤湿度传感器
│    ├── 流量传感器
│    └── 压力传感器
│  
└── 网关系列    
	 └── LoraWAN网关
```

### 1.2 产品特点

**通用特点**：
- 智能控制，支持远程操作
- 低功耗设计，节能环保
- 多种通信方式可选
- 工业级防护，适合户外使用
- 支持云平台对接

## 三、产品选型指南

### 3.1 选型依据

| 因素 | 考虑要点 |
|------|----------|
| 应用场景 | 农田、园林、家庭等 |
| 灌溉面积 | 小型/中型/大型 |
| 通信距离 | 短距离/长距离 |
| 供电方式 | 市电/太阳能 |

### 3.2 推荐方案

| 场景 | 推荐配置 |
|------|----------|
| 家庭花园 | QT-DTU-4G + QT-F08 |
| 小型农田 | QT-DTU-4G + QT-F12 + 传感器 |
| 大型农场 | QT-DTU-LoRa + QT-F30 + 传感器 + 气象站 |
| 园林绿地 | QT-DTU-4G + QT-F12/QT-F30 |
