# 📡 DTU产品

本文档详细介绍强泰DTU控制器系列产品。

---

## 一、产品概述

### 1.1 DTU系列

强泰DTU控制器是智慧灌溉系统的核心控制单元，负责数据采集和设备控制。

| 型号 | 通信方式 | 说明 |
|------|----------|------|
| QT-DTU-4G | 4G+RS485+蓝牙 | 基础款，适合4G覆盖区域 |
| QT-DTU-LoRa | 4G+LoRaWAN+RS485 | 支持LoRaWAN，适合偏远区域 |

### 1.2 产品特点

**通用特点**：
- 支持多种通信方式
- 工业级设计，稳定可靠
- 支持远程配置和升级
- 低功耗设计

## 二、技术参数

### 2.1 QT-DTU-4G

**基本参数**：
| 参数 | 规格 |
|------|------|
| 处理器 | ARM Cortex-M4 |
| 内存 | 64MB Flash / 32MB RAM |
| 工作温度 | -40°C ~ +85°C |
| 防护等级 | IP67 |

**通信参数**：
| 参数 | 规格 |
|------|------|
| 4G模块 | LTE Cat.4 |
| 频段 | B1/B3/B5/B8/B34/B38/B39/B40/B41 |
| RS485 | 支持，300-115200bps |
| 蓝牙 | BLE 5.0 |

**接口参数**：
| 参数 | 规格 |
|------|------|
| 继电器输出 | 4路，DC 12V/24V，最大5A |
| 传感器输入 | 8路模拟/数字输入 |
| 电源输入 | DC 9-36V |
| 功耗 | ≤5W（待机≤0.5W） |

### 2.2 QT-DTU-LoRa

**基本参数**：
| 参数 | 规格 |
|------|------|
| 处理器 | ARM Cortex-M4 |
| 内存 | 64MB Flash / 32MB RAM |
| 工作温度 | -40°C ~ +85°C |
| 防护等级 | IP67 |

**通信参数**：
| 参数 | 规格 |
|------|------|
| 4G模块 | LTE Cat.4 |
| LoRaWAN | 支持，EU868/US915/CN470/AU915/AS923 |

**接口参数**：
| 参数 | 规格 |
|------|------|
| 继电器输出 | 4路，DC 12V/24V，最大5A |
| 传感器输入 | 8路模拟/数字输入 |

| 功耗 | ≤8W（待机≤0.5W） |

## 三、安装指南

### 3.1 安装步骤

**安装前准备**：
1. 检查设备包装完好
2. 准备安装配件（螺丝、防水接头等）
3. 准备SIM卡（需开通数据业务）

**安装步骤**：
1. 安装SIM卡到卡槽
2. 固定设备到安装位置
3. 连接电源线
4. 连接传感器和阀门
5. 拧紧防水接头
6. 上电测试

### 3.2 接口说明

**接口布局**：
```
正面接口：
├── 电源接口（DC 9-36V）
├── 继电器输出接口（4路）
├── 传感器输入接口（8路）
└── RS485接口（A/B/GND）

侧面接口：
├── SIM卡槽
└── 复位按钮
```

## 四、通信配置

### 4.1 4G配置

**APN配置**：
- 默认APN：CMNET（移动）/UNINET（联通）/CTNET（电信）
- 支持自动获取APN

**网络注册**：
- 设备上电后自动搜索网络
- 自动连接云平台
- 支持信号强度指示

### 4.2 RS485配置

**参数设置**：
| 参数 | 默认值 | 可选范围 |
|------|--------|----------|
| 波特率 | 9600 | 300-115200 |
| 数据位 | 8 | 7-8 |
| 停止位 | 1 | 1-2 |
| 校验位 | None | None/Odd/Even |

### 4.3 LoRaWAN配置（仅LoRa型号）

**参数设置**：
| 参数 | 说明 |
|------|------|
| DevEUI | 设备唯一标识 |
| AppEUI | 应用标识 |
| AppKey | 应用密钥 |
| 频段 | 根据区域选择 |

## 五、设备管理

### 5.1 设备激活

**激活步骤**：
1. 登录强泰云平台
2. 进入设备管理页面
3. 点击"添加设备"
4. 扫描设备二维码或输入设备ID
5. 等待设备上线（约1-2分钟）

### 5.2 远程配置

**配置项**：
- 网络参数
- 传感器参数
- 定时任务
- 告警阈值

### 5.3 远程升级

**升级流程**：
1. 上传固件到平台
2. 选择设备发起升级
3. 设备自动下载并升级
4. 升级完成后自动重启
