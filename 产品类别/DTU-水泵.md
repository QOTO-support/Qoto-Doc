# 💧 DTU-水泵控制模块

本文档详细介绍DTU控制器的水泵控制功能。

---

## 一、水泵控制概述

### 1.1 水泵控制功能

强泰DTU控制器支持水泵的智能控制，实现灌溉系统的自动化管理。

**主要功能**：
- 水泵开关控制
- 水泵状态监测
- 过载保护
- 联动控制

### 1.2 应用场景

**典型应用**：
- 农田灌溉水泵控制
- 园林绿地供水系统
- 蓄水池供水控制
- 滴灌系统水泵管理

---

## 二、技术参数

### 2.1 水泵控制输出

**输出参数**：
| 参数 | 规格 |
|------|------|
| 输出类型 | 继电器输出 |
| 输出路数 | 1路（可扩展） |
| 额定电压 | DC 12V/24V |
| 最大电流 | 5A |

### 2.2 状态监测

**监测参数**：
| 参数 | 说明 |
|------|------|
| 水泵状态 | 运行/停止 |
| 电流监测 | 运行电流 |
| 故障状态 | 过载/短路/缺相 |

---

## 三、水泵控制配置

### 3.1 接线配置

**接线方式**：
```
DTU继电器输出
├── COM端子 → 电源正极
├── NO端子 → 水泵控制器正极
└── 水泵控制器负极 → 电源负极
```

**水泵控制器连接**：
```
水泵控制器
├── 电源输入 → DC 12V/24V
├── 控制输入 → DTU继电器输出
├── 状态反馈 → DTU数字输入
└── 水泵电机 → 三相电源
```

### 3.2 控制参数配置

**配置步骤**：
1. 登录云平台
2. 进入设备配置页面
3. 选择水泵控制配置
4. 设置控制参数
5. 保存配置

**配置参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 启动延时 | 0s | 启动前延时 |
| 停止延时 | 0s | 停止前延时 |
| 过载电流阈值 | 10A | 过载保护阈值 |
| 启动间隔 | 60s | 两次启动最小间隔 |

---

## 四、控制方式

### 4.1 手动控制

**远程控制**：
1. 登录云平台
2. 进入设备详情页
3. 找到水泵控制按钮
4. 点击"启动"或"停止"
5. 确认操作

**本地控制**：
- 通过DTU本地按钮控制
- 通过蓝牙APP控制

### 4.2 定时控制

**设置步骤**：
1. 进入定时任务页面
2. 添加水泵控制任务
3. 设置执行时间
4. 设置执行动作（启动/停止）
5. 保存任务

### 4.3 联动控制

**联动规则**：
- 阀门打开时自动启动水泵
- 所有阀门关闭时自动停止水泵
- 水位低于阈值时停止水泵
- 过载时自动停止并告警

---

## 五、保护功能

### 5.1 过载保护

**保护机制**：
- 实时监测水泵电流
- 超过阈值时自动停止
- 发送告警通知
- 记录故障日志

**恢复方式**：
- 手动恢复
- 自动恢复（延时后重试）

### 5.2 短路保护

**保护机制**：
- 检测输出短路
- 立即切断输出
- 发送告警通知

### 5.3 缺相保护（三相水泵）

**保护机制**：
- 监测三相电源
- 缺相时立即停止
- 发送告警通知

---

## 六、状态监测

### 6.1 实时状态

**监测内容**：
- 水泵运行状态
- 运行时长
- 累计运行次数
- 电流值

### 6.2 历史记录

**记录内容**：
- 启动/停止时间
- 运行时长
- 故障记录
- 告警记录
