# 🔗 平台对接

本文档详细介绍客户平台系统对接强泰云平台的方法。

---

## 一、对接概述

### 1.1 对接方式

客户平台通过API接口与强泰云平台对接，实现数据同步和设备控制。

**对接架构**：
```
客户平台 ←→ API接口 ←→ 强泰云平台 ←→ 设备
```

**对接特点**：
- 基于RESTful API设计

### 1.2 适用场景

**适用客户**：
- 需要与现有业务系统集成
- 需要自定义业务逻辑

---

## 二、准备工作

### 2.1 账号注册

**注册步骤**：
1. 下载APP : 各大应用市场搜索：iotmgr
2. 用手机号+验证码注册 

### 2.2 API密钥管理
	1、登录电脑端系统：https://smart1688.net/#/login  
	2、进入菜单【开放平台】 然后【+添加】 填写回调地址（用于接收强泰平台推送数据的接口）。appid+密钥会自动生成
	3、回调接口返回数据get参数如下：
	
``` 
String deviceId, 设备编码

Integer percentage, 阀门开度

Integer electric, 设备电量

BigDecimal totalFlow , 总流量 单位：L

BigDecimal singleFlow , 单次流量 单位：L

BigDecimal momFlow, 瞬时流量 单位L/S

Integer signalValue , 信号值

String logType 日志类型：B0 ：心跳 B3 ：开阀之后中间数据，B4开关阀数据上报

valveType: 阀门类型，值：单通-00、三通-01

valveStatus 阀门方位 A-00 或者B-01

pressure 压力 单位:Pa
```

## 三、API接口

**3.1、接口及返回
https://smart1688.net/prod_api

根据上面步骤获取的【appid+密钥 】进行相关业务接口的调用 ，具体开放平台接口参考
https://s23ktrcks5.apifox.cn

``` json
{ 
	"tx_code": "00", 
	"error_info": 
		{ 
			"code": "",
			"message": "", 
			"url": "" 
		 }, 
	"data": false 
}
```

**3.2、返回code

response status = 200 正常
	常见tx_code返回码
	00 : 正常成功 ，
	其他 ： 具体看返回error_info.message
response status = 401 token过期；
response status = 403 无权限；


**3.3、推送重试策略**：
重试3次 （指数退避）： 10秒、30秒、1分钟
