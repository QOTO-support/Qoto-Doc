# 系统对接

本文档介绍客户如何将自己的系统与强泰智慧灌溉系统进行对接。

---

## 一、对接方式概述

强泰智慧灌溉系统支持两种对接方式，满足不同客户的需求：

| 对接方式 | 说明 | 适用场景 |
|----------|------|----------|
| 平台对接 | 客户平台系统对接强泰云平台 | 需要统一管理、数据分析的客户 |
| 设备直连 | 设备直接连接客户自己的MQTT Broker | 需要数据本地化、独立部署的客户 |

---

## 二、对接方式选择

### 2.1 方式对比

| 项目 | 平台对接 | 设备直连 |
|------|----------|----------|
| 数据路径 | 设备→强泰云→客户平台 | 设备→客户Broker→客户平台 |
| 部署复杂度 | 低 | 高 |
| 维护成本 | 低 | 高 |
| 数据控制权 | 强泰云 | 客户 |
| 网络依赖 | 依赖强泰云 | 独立 |
| 扩展性 | 强 | 中等 |
| 适用规模 | 中小型 | 大型/企业级 |

### 2.2 选型建议

| 客户类型 | 推荐方式 | 原因 |
|----------|----------|------|
| 小型农场 | 平台对接 | 简单易用，无需运维 |
| 中型园区 | 平台对接 | 平衡成本与功能 |
| 大型企业 | 设备直连 | 数据本地化，自主可控 |
| 政府项目 | 设备直连 | 安全合规要求 |
