# 📋 常规故障排查

本文档介绍常规故障的排查方法和解决步骤。

---

## 一、网络连接问题

### 1.1 4G网络连接失败

**排查步骤**：
1. 检查SIM卡状态
2. 检查信号强度
3. 检查APN配置
4. 检查网络运营商

**故障排除**：
```
1. 进入设备配置页面
2. 查看SIM卡状态 → 如果未检测到，检查SIM卡安装
3. 查看信号强度 → 如果信号弱，调整安装位置
4. 检查APN设置 → 确保APN正确
5. 重启设备测试
```

### 1.2 LoRaWAN连接失败

**排查步骤**：
1. 检查网关状态
2. 检查设备配置
3. 检查频段设置
4. 检查服务器连接

**故障排除**：
```
1. 登录LoRaWAN网络服务器
2. 查看网关状态 → 确保网关在线
3. 检查设备DevEUI → 确认设备已注册
4. 检查频段配置 → 确保与网关一致
5. 重新激活设备
```

## 二、数据传输问题

### 2.1 上行数据延迟

**排查步骤**：
1. 检查网络状态
2. 检查设备负载
3. 检查服务器负载
4. 检查数据队列

**优化建议**：
- 调整数据上报频率
- 使用批量上报
- 优化网络连接

### 2.2 下行指令延迟

**排查步骤**：
1. 检查设备在线状态
2. 检查指令队列
3. 检查网络延迟
4. 检查设备处理能力

**优化建议**：
- 减少并发指令
- 优化指令优先级
- 检查设备资源

---

## 三、设备同步问题

### 3.1 时间同步失败

**排查步骤**：
1. 检查网络连接
2. 检查NTP配置
3. 检查时区设置
4. 手动同步时间

**解决步骤**：
```
1. 检查NTP服务器配置
2. 确保网络可以访问NTP服务器
3. 手动同步时间：
   - 登录设备配置页面
   - 设置当前时间
   - 保存配置
```

### 3.2 配置同步失败

**排查步骤**：
1. 检查设备在线状态
2. 检查配置指令
3. 检查设备响应
4. 检查配置格式

**解决步骤**：
```
1. 确保设备在线
2. 检查配置参数格式
3. 重新发送配置
4. 检查配置返回结果
```

## 四、系统性能问题

### 4.1 平台响应慢

**排查步骤**：
1. 检查网络延迟
2. 检查服务器负载
3. 检查浏览器缓存
4. 检查页面资源

**优化建议**：
- 清除浏览器缓存
- 使用CDN加速
- 减少页面加载资源

### 4.2 设备响应慢

**排查步骤**：
1. 检查设备CPU负载
2. 检查内存使用
3. 检查网络连接
4. 检查任务队列

**优化建议**：
- 减少并发任务
- 优化数据采集频率
- 升级设备固件

---

## 五、数据存储问题

### 5.1 数据丢失

**排查步骤**：
1. 检查网络连接
2. 检查数据上传日志
3. 检查服务器存储
4. 检查数据备份

**恢复措施**：
- 检查设备本地缓存
- 从备份恢复数据
- 重新上传历史数据

### 5.2 数据重复

**排查步骤**：
1. 检查数据上报逻辑
2. 检查重复检测机制
3. 检查数据去重配置
4. 检查网络重传

**解决措施**：
- 启用数据去重
- 设置数据上报间隔
- 检查网络稳定性

---

## 六、安全问题

### 6.1 认证失败

**排查步骤**：
1. 检查账号密码
2. 检查Token有效期
3. 检查IP白名单
4. 检查权限配置

**解决措施**：
- 重置密码
- 重新获取Token
- 检查IP配置
- 申请权限


| 故障现象      | 故障原因                   | 故障解决方法           |
| --------- | ---------------------- | ---------------- |
| 扫码添加设备没响应 | 二维码表面有污渍或破损不完整         | 手动输入二维码旁边的设备编号   |
| 设备编号不存在   | 设备编号输入错误               | 输入正确的设备编号        |
| 设备已绑定     | 设备已被添加绑定               | 咨询原设备用户解绑后，再添加   |
|           |                        | 主账号分配子账号，用子账号再添加 |
|           |                        | 联系技术支持，后台解绑      |
| 设备离线      | 设备未解除休眠，处于休眠休眠状态，没有入网。 | 使用按键或磁控棒进行触控解除休眠 |
|           | 没装SIM卡，或SIM安装不正确       | 正确安装SIM卡         |
|           | 设备没电                   | 检查电池是否安装并连接好     |
|           |                        | 电池没电更换电池         |
|           |                        | 电池或供电规格不符合设备要求   |
