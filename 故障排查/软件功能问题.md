# 💻 软件功能问题

本文档详细介绍软件功能相关故障的排查方法。

---

## 一、平台登录问题

### 1.1 无法登录平台

**排查步骤**：
1. 检查网络连接
2. 检查用户名和密码
3. 检查账号是否被锁定
4. 检查浏览器兼容性

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 网络异常 | 检查网络连接 |
| 账号密码错误 | 找回密码 |
| 账号被锁定 | 联系管理员解锁 |
| 浏览器问题 | 使用推荐浏览器 |

### 1.2 登录后页面异常

**排查步骤**：
1. 刷新页面
2. 清除浏览器缓存
3. 检查浏览器版本
4. 尝试其他浏览器

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 缓存问题 | 清除缓存 |
| 浏览器版本过低 | 升级浏览器 |
| JavaScript错误 | 刷新页面 |

## 二、设备管理问题

### 2.1 设备添加失败

**排查步骤**：
1. 检查设备ID是否正确
2. 检查设备是否已被添加
3. 检查设备是否在线
4. 检查网络连接

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 设备ID错误 | 核对设备ID |
| 设备已添加 | 查看设备列表 |
| 设备离线 | 检查设备网络 |
| 网络超时 | 稍后重试 |

### 2.2 设备状态异常

**排查步骤**：
1. 检查设备实际状态
2. 检查网络连接
3. 检查平台状态
4. 检查设备配置

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 设备离线 | 恢复网络 |
| 平台故障 | 等待恢复 |
| 配置错误 | 检查配置 |

## 三、定时任务问题

### 3.1 任务不执行

**排查步骤**：
1. 检查任务状态
2. 检查任务时间设置
3. 检查设备状态
4. 检查任务日志

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 任务未启用 | 启用任务 |
| 时间设置错误 | 修正时间 |
| 设备离线 | 恢复设备连接 |
| 任务冲突 | 检查任务调度 |

### 3.2 任务执行异常

**排查步骤**：
1. 查看任务执行日志
2. 检查任务参数
3. 检查设备响应
4. 检查网络延迟

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 参数错误 | 修正参数 |
| 设备无响应 | 检查设备 |
| 网络延迟 | 调整执行时间 |

| 处理异常 | 联系技术支持 |
