# 🛠️ 故障排查手册

本文档是智慧灌溉系统故障排查的总览指南。

---

## 一、故障排查概述

### 1.1 故障分类

**故障类型**：

| 类别 | 说明 | 常见原因 |
|------|------|----------|
| 硬件故障 | 设备硬件损坏 | 电源问题、接口损坏、元器件故障 |
| 软件故障 | 软件功能异常 | 配置错误、固件问题、网络问题 |
| 通信故障 | 数据传输异常 | 网络连接、协议配置、信号问题 |
| 传感器故障 | 传感器数据异常 | 接线问题、校准问题、传感器损坏 |

### 1.2 排查流程

**通用排查步骤**：
1. **确认故障现象**：记录故障表现、时间、频率
2. **查看设备状态**：检查指示灯、在线状态
3. **查看日志信息**：查看设备日志、平台日志
4. **逐一排除**：从简单到复杂逐步排查
5. **验证解决方案**：修复后验证是否恢复正常

## 二、快速排查

### 2.1 设备离线

**排查步骤**：
1. 检查电源是否正常
2. 检查SIM卡是否插入正确
3. 检查信号强度
4. 检查网络注册状态
5. 检查服务器连接

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 电源断开 | 检查电源连接 |
| SIM卡问题 | 重新插拔SIM卡 |
| 信号弱 | 调整安装位置 |
| APN错误 | 检查APN配置 |

### 2.2 数据不更新

**排查步骤**：
1. 检查设备是否在线
2. 检查传感器连接
3. 检查采集周期设置
4. 检查数据上传配置

**常见原因**：

| 原因     | 解决方案    |
| ------ | ------- |
| 传感器未连接 | 检查接线    |
| 传感器故障  | 更换传感器   |
| 采集周期过长 | 调整采集周期  |
| 网络延迟   | 等待或检查网络 |

### 2.3 控制指令不执行

**排查步骤**：
1. 检查设备在线状态
2. 检查指令格式
3. 检查阀门连接
4. 检查继电器输出

**常见原因**：

| 原因 | 解决方案 |
|------|----------|
| 设备离线 | 恢复网络连接 |
| 指令格式错误 | 检查指令参数 |
| 阀门接线错误 | 检查接线 |
| 继电器故障 | 更换继电器 |

## 三、故障码速查

### 3.1 故障码列表

**故障码定义**：

| 故障码 | 说明 | 解决方案 |
|--------|------|----------|
| E001 | 电源电压异常 | 检查电源输入 |
| E002 | SIM卡未检测到 | 检查SIM卡 |
| E003 | 网络注册失败 | 检查信号和APN |
| E004 | 服务器连接失败 | 检查服务器地址 |
| E005 | 传感器通信异常 | 检查传感器接线 |
| E006 | 阀门控制失败 | 检查阀门连接 |
| E007 | 固件升级失败 | 重新升级固件 |
| E008 | 存储异常 | 重启设备 |

### 3.2 状态指示灯

**指示灯含义**：

| 指示灯 | 状态 | 含义 |
|--------|------|------|
| 电源灯 | 常亮绿色 | 电源正常 |
| 电源灯 | 闪烁红色 | 电源异常 |
| 网络灯 | 常亮绿色 | 网络连接正常 |
| 网络灯 | 闪烁绿色 | 网络连接中 |
| 网络灯 | 熄灭 | 网络未连接 |
| 运行灯 | 闪烁绿色 | 设备正常运行 |
| 运行灯 | 常亮红色 | 设备故障 |
